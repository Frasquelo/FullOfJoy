Note per la sostituzione

Come sostituire una foto:

  1. Scegli la nuova foto e salvala in WebP (usa squoosh.app per convertire gratis).
  2. Rinomina il file con lo stesso nome della foto da sostituire (es. convivenza.webp) — così non devi toccare il codice HTML.
  3. Copia il file nella cartella FullOfJoy/img/ (o assets/ per l'hero).
  4. Per le foto usate come sfondo CSS (HERO) le dimensioni consigliate sono 1400×700 px min. Per le card vanno bene 800×600 px. Per gli avatar collaboratori: 200×200 px.

Priorità consigliate (per impatto visivo + peso):

  1. assets/hero-tre-cime.webp — hero homepage, massima visibilità
  2. assets/hero-cane.jpg — og:image (WhatsApp/Facebook share)
  3. img/silvia.webp — ritratto Silvia, alta visibilità
  4. img/convivenza.webp — 246 KB, più pesante della griglia
  5. img/classi-socializzazione.webp — 212 KB
  6. img/educazione-base.webp — 222 KB
